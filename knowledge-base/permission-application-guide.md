# 权限申请与访问控制指南

## 1. 什么是最小权限原则

最小权限原则是指用户只应拥有完成当前工作所必需的最低权限，不应长期持有与工作无关或超出职责范围的权限。

最小权限可以降低账号被盗、误操作、越权访问和数据泄露的风险。

## 2. 如何申请系统权限

申请系统权限时，用户应说明申请原因、使用场景、所需权限范围、使用期限和审批人。权限申请应通过学校或企业指定流程提交，不建议通过口头、私聊或非正式方式授予权限。

管理员在审批时，应确认申请是否必要、权限范围是否合理、是否存在替代方案，以及权限是否需要设置有效期。

## 3. 临时权限如何处理

临时权限应设置明确有效期。使用结束后，应及时回收权限，避免权限长期保留。

如果临时权限涉及敏感系统、管理后台或重要数据访问，应加强审批和记录。

## 4. 外部人员访问系统需要注意什么

外部人员访问系统应经过正式审批，明确访问目的、访问范围、访问期限和责任人。不应随意共享内部账号或将个人账号借给外部人员使用。

外部访问结束后，应及时关闭账号或回收权限。

## 5. 权限异常怎么办

如果用户发现自己拥有不应拥有的权限，或发现他人疑似越权访问，应及时联系系统管理员核查。

如果权限异常涉及敏感数据、管理后台或重要系统，应视为较高风险问题处理。

## 6. 权限管理原则

1. 权限申请应有明确目的。
2. 权限范围应尽量小。
3. 临时权限应设置有效期。
4. 外部访问应正式审批。
5. 权限异常应及时联系管理员。
