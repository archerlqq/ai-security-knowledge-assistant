# 钓鱼邮件识别与处理指南

## 1. 什么是钓鱼邮件

钓鱼邮件是指伪装成学校、企业、平台、银行、快递、通知系统等可信来源，诱导用户点击链接、下载附件、填写账号密码或提供验证码的邮件。

钓鱼邮件的风险在于，它可能导致账号被盗、敏感信息泄露、恶意软件感染或权限被滥用。

## 2. 如何识别可疑邮件

用户可以从以下方面判断邮件是否可疑：

1. 发件人地址是否异常，例如域名拼写错误、使用陌生邮箱或与官方域名不一致。
2. 邮件是否制造紧张感，例如要求立即处理、否则封号、停用账号或影响权限。
3. 邮件中是否包含陌生链接、短链接、附件或二维码。
4. 邮件是否要求输入账号、密码、验证码、身份证号等敏感信息。
5. 邮件措辞是否存在明显错误、格式异常或内容不符合正常流程。

## 3. 收到疑似钓鱼邮件怎么办

用户收到疑似钓鱼邮件时，不应点击邮件中的链接，不应下载附件，也不应扫描二维码或填写个人信息。

建议用户先通过官方渠道核实邮件真实性。如果无法判断，应将邮件转发或截图给信息中心、安全管理员或相关负责人进行核验。

如果用户已经点击链接或提交了账号密码，应立即修改密码，并联系管理员检查账号状态。

## 4. 为什么不能随意点击邮件链接

钓鱼邮件中的链接可能指向伪造登录页或恶意网站。用户输入账号密码后，攻击者可能获取账号凭证并进一步访问系统或数据。

因此，涉及登录、支付、权限、账号验证等操作时，应优先通过官方网站或系统入口访问，而不是直接点击邮件中的链接。

## 5. 钓鱼邮件处理原则

1. 不点击可疑链接。
2. 不下载未知附件。
3. 不填写账号密码和验证码。
4. 通过官方渠道核实。
5. 已经点击或提交信息时，及时修改密码并联系管理员。
