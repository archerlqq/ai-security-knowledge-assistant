# 钓鱼邮件处理指南

## 1. 什么是疑似钓鱼邮件？

疑似钓鱼邮件通常包含异常发件人地址、伪装成官方通知、诱导点击链接、要求输入账号密码、包含可疑附件或制造紧急压力等特征。

## 2. 收到疑似钓鱼邮件怎么办？

用户不应点击邮件中的链接，也不应下载或打开可疑附件。应先核对发件人地址、链接域名和邮件内容是否与正常业务一致。如果无法确认，应联系信息中心或安全管理员进行核验。

## 3. 已经点击了可疑链接怎么办？

如果用户已经点击可疑链接，但没有输入账号密码，应关闭页面，并观察账号是否存在异常情况。如果已经输入账号密码，应立即修改密码，并联系管理员检查账号状态。

## 4. 如何降低钓鱼邮件风险？

用户应避免在不明页面输入账号密码，不随意下载邮件附件，不轻信带有紧急、中奖、账号冻结等诱导性语言的邮件。
