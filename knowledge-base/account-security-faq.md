# 账号安全 FAQ

## 1. 账号疑似被盗怎么办

如果用户发现账号疑似被盗，应立即停止继续使用该账号进行重要操作，并尽快修改密码。修改密码时，应避免使用与旧密码相似的组合，也不要使用生日、手机号、姓名拼音、简单数字等容易被猜到的信息。

用户还应检查近期登录记录、账号绑定信息、邮箱、手机号和多因素认证设置。如果发现异常登录、陌生设备、异常绑定或权限变化，应及时联系信息中心或系统管理员处理。

如果该账号涉及重要系统、管理权限、数据访问权限或财务相关操作，应将风险等级视为较高，建议立即联系管理员进行冻结、核查或权限回收。

## 2. 如何设置强密码

强密码应具备足够长度和复杂度，建议同时包含大小写字母、数字和符号，并避免使用个人信息、常见词语、连续数字或重复字符。

不同系统应尽量使用不同密码，避免多个平台共用同一密码。如果一个平台发生密码泄露，共用密码可能导致其他账号也受到影响。

## 3. 什么是多因素认证

多因素认证是指除密码之外，再增加短信验证码、动态口令、认证 App、硬件密钥等额外验证方式。它可以降低单一密码泄露带来的风险。

对于重要系统、管理后台、邮箱和云服务账号，建议开启多因素认证。

## 4. 收到异常登录提醒怎么办

如果用户收到异常登录提醒，应先确认是否为本人操作。如果不是本人操作，应立即修改密码，并检查账号绑定信息、登录设备和近期操作记录。

如账号涉及重要系统或敏感数据访问，应联系管理员进行安全核查。

## 5. 账号安全处理原则

账号安全问题应遵循以下原则：

1. 及时修改密码。
2. 检查异常登录和绑定信息。
3. 避免继续使用疑似异常账号处理重要事务。
4. 涉及重要系统或敏感数据时联系管理员。
5. 不向任何人提供密码、验证码或账号凭证。
