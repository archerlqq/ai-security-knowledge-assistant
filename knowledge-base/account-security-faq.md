# 账号安全 FAQ

## 1. 账号疑似被盗怎么办？

如果用户发现账号出现异地登录、密码被修改、无法正常登录、异常操作记录等情况，应优先判断是否存在账号泄露风险。用户应立即修改密码，检查近期登录记录，并联系信息中心或系统管理员确认账号状态。

如果该账号涉及重要系统权限，应暂停相关操作，避免继续使用可能已经存在风险的账号处理敏感信息。

## 2. 如何设置更安全的密码？

建议使用长度较长、包含大小写字母、数字和特殊符号的密码，避免使用生日、手机号、姓名拼音、连续数字等容易被猜测的信息。不同系统不建议使用完全相同的密码。

## 3. 密码是否可以告诉他人？

账号和密码属于个人身份凭证，不应通过聊天软件、邮件或共享文档等方式告知他人。如果确需他人协助处理系统问题，应通过正式授权或管理员协助完成，而不是直接共享密码。

## 4. 发现异常登录记录怎么办？

如果发现异常登录记录，用户应立即修改密码，并检查账号绑定信息是否被修改。如果账号涉及重要业务系统，应及时联系管理员进一步核查。
