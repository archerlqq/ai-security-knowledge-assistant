# 数据安全注意事项

## 1. 哪些数据需要谨慎处理？

涉及个人信息、学生信息、账号凭证、科研数据、业务数据、内部文件等内容时，应谨慎处理。此类数据不应随意通过公开网盘、社交群聊或不受控平台传输。

## 2. 文件可以上传到外部网盘吗？

如果文件包含个人信息、学生信息、内部业务数据或敏感内容，不建议上传到外部网盘。应优先使用学校或企业指定的文件传输和存储系统。

## 3. 班级名单可以发到微信群吗？

如果班级名单包含姓名、学号、手机号、身份证号、成绩等个人信息，应谨慎处理，不建议随意发送到公开或半公开群聊中。确需共享时，应控制范围，并避免包含不必要的敏感字段。

## 4. 数据外发需要注意什么？

数据外发前应确认数据类型、接收方身份、传输渠道和审批要求。涉及敏感数据时，应按照学校或企业的数据安全管理要求处理。
