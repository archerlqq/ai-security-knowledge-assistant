# 数据安全与个人信息处理指南

## 1. 什么是敏感数据

敏感数据包括但不限于个人身份信息、学生信息、联系方式、身份证号、账号凭证、成绩信息、科研数据、业务数据、系统日志、访问权限信息等。

在高校或企业场景中，学生名单、联系方式、成绩表、科研资料、内部系统数据等都可能涉及数据安全风险。

## 2. 处理个人信息时应注意什么

处理个人信息时，应遵循必要、最小、明确用途的原则。只收集完成业务所必需的信息，不应随意扩大收集范围。

在共享、传输、存储个人信息时，应确认接收对象、使用目的和保存方式是否合理。对于包含大量个人信息的文件，应避免通过公开网盘、社交群聊或不受控平台传输。

## 3. 学生名单能不能发到微信群

如果学生名单包含姓名、学号、手机号、身份证号、成绩、家庭住址等信息，应谨慎处理。是否可以发送，需要看发送目的、群成员范围、是否有必要、是否经过授权以及是否存在泄露风险。

一般情况下，不建议将包含个人信息的表格直接发送到非正式群聊中。更稳妥的做法是使用学校或企业指定系统，或在必要时进行脱敏处理。

## 4. 科研数据能不能上传个人网盘

科研数据是否可以上传个人网盘，需要考虑数据性质、课题要求、合作协议、保密要求和平台安全性。

对于涉及未公开成果、合作单位资料、个人信息、敏感实验数据或商业秘密的数据，不建议上传到个人网盘或不受控平台。应优先使用学校或机构指定的存储系统。

## 5. 数据安全处理原则

1. 只收集必要数据。
2. 避免通过不受控渠道传输敏感数据。
3. 涉及个人信息时注意脱敏和访问范围。
4. 重要数据应使用指定系统存储。
5. 发生误发、泄露或异常访问时，应及时联系管理员。
